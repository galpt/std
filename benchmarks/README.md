# STD Benchmarks

Placeholder for future STD measurements. No results are published yet.
Planned work covers wakeup latency and placement spread across the
allowed mask, plus predictor influence (`nn_keep` vs `nn_migrate`),
whole-core hit rate (`split_core`) and the vertical
`fastpath`/`steered`/`fallback` outcomes. No isolation requirement;
trio presence is optional and does not affect the measured paths.
